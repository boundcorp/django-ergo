## Overview

The current conversation runtime separates an engine protocol, persisted session identity, session-owned engine instances, and a bounded tool loop. Engines translate provider events into `EngineResponse` values; the runner decides when tools execute or when control must return for approval.

## Runtime

`Engine` defines session start/resume/close, message generation, single or batched tool-result submission, and adapter access. `SessionManager` creates the persisted ConversationSession, builds the configured engine, caches it by session UUID, and reconstructs it on demand. `run_conversation_turn` injects schemas from extra toolkits, records bound-KB usage, sends the user message, and processes at most the configured number of tool rounds.

## Boundaries

A toolkit handles a tool before the global registry. Toolkit `ValueError`, `KeyError`, `TypeError`, and `RuntimeError` exceptions become error tool results so the model can correct arguments. Global tools execute through the registry with the session user. A registry tool marked `requires_approval` yields `PendingApproval` unless the workflow configuration pre-approves it; the turn returns without executing that tool.

## Concrete Flow

1. `SessionManager.create_session` persists an active session and starts its engine.
2. `run_conversation_turn` sends a message with any extra toolkit schemas.
3. The runner batches one round's tool calls. An approval-required call stops the turn; otherwise `_execute_tool` dispatches each call and reports recoverable failures as tool errors.
4. Batched results return to the engine, and the cycle continues until no tool calls remain or the round bound is reached.

## Termination

`SessionManager.close_session` removes the cached engine, invokes its `close_session` hook, marks the persisted session `completed`, and saves it. The OpenAI and Claude API implementations currently treat provider sessions as stateless and implement that hook as a no-op; callers should not infer transport-resource cleanup beyond the protocol call.
